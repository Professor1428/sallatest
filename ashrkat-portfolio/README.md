# موقع أشرقت كريم - بورتفوليو تسويق وتصميم (PHP)

موقع بورتفوليو ديناميكي كامل بلغة PHP، مع لوحة تحكم لإدارة كل محتوى الموقع
(النصوص، الألوان، الباقات، الصور، دراسات الحالة، آراء العملاء، الرسائل الواردة)
بدون الحاجة لأي معرفة برمجية.

## المتطلبات

- استضافة تدعم PHP 8.1 أو أحدث (مع امتداد GD مفعّل - موجود افتراضيًا في أغلب الاستضافات).
- لا حاجة لقاعدة بيانات منفصلة: الموقع يستخدم SQLite افتراضيًا (ملف واحد يُنشأ تلقائيًا).
  إذا كانت استضافتك توفر MySQL وتفضلين استخدامه، التعليمات أدناه.

## التركيب (الرفع على الاستضافة)

1. ارفعي كل محتويات هذا المجلد إلى مجلد الاستضافة (public_html أو ما يعادله) عبر FTP
   أو مدير الملفات في لوحة الاستضافة (cPanel).
2. افتحي ملف `config/config.php` وغيّري القيمة التالية إلى نص سري خاص بك
   (استخدميه مرة واحدة فقط لإنشاء حساب الدخول الأول، ثم لا تشاركيه مع أحد):
   ```php
   define('SETUP_KEY', 'اكتبي هنا نصًا عشوائيًا صعب التخمين');
   ```
3. افتحي في المتصفح: `https://your-domain.com/admin/install.php`
   وأدخلي مفتاح الإعداد الذي وضعتِه، واسم مستخدم وكلمة مرور لحسابك في لوحة التحكم.
   هذه الصفحة تعمل مرة واحدة فقط ولا يمكن الوصول إليها بعد إنشاء أول حساب.
4. سجّلي الدخول من `https://your-domain.com/admin/login.php` وابدئي بتعديل
   بياناتك من قسم "الإعدادات العامة"، ثم أضيفي صور معرض أعمالك.

الموقع نفسه يظهر على `https://your-domain.com/` (ملف `index.php`).

## استخدام MySQL بدلاً من SQLite (اختياري)

إذا أردتِ استخدام قاعدة بيانات MySQL من لوحة الاستضافة (cPanel → MySQL Databases):

1. أنشئي قاعدة بيانات ومستخدمًا في لوحة الاستضافة وامنحيه كل الصلاحيات عليها.
2. عدّلي في `config/config.php`:
   ```php
   define('DB_DRIVER', 'mysql');
   define('DB_HOST', '127.0.0.1');
   define('DB_NAME', 'اسم قاعدة البيانات');
   define('DB_USER', 'اسم المستخدم');
   define('DB_PASS', 'كلمة المرور');
   ```
3. افتحي الموقع - سيتم إنشاء كل الجداول تلقائيًا عند أول زيارة.

## ما يمكنك التحكم به من لوحة التحكم

- **الإعدادات العامة**: الاسم، المسمى الوظيفي، النصوص التعريفية، بيانات التواصل،
  وألوان الموقع بالكامل (تُطبَّق فورًا على كامل التصميم).
- **المهارات**: إضافة/تعديل/حذف تصنيفات المهارات وعناصرها بحرية تامة.
- **الباقات والخدمات**: تعديل الباقات الثلاث أو إضافة باقات جديدة، وتحديد
  الباقة "الأكثر طلبًا".
- **دراسات الحالة**: إضافة مشاريع جديدة مع رفع صورة لكل مشروع.
- **معرض الأعمال**: رفع صور أعمالك وترتيبها وحذفها.
- **آراء العملاء**: إضافة وتعديل شهادات العملاء وتقييماتها.
- **الرسائل الواردة**: كل رسالة تصل من نموذج التواصل بالموقع تظهر هنا مباشرة.
- **كلمة المرور**: تغيير كلمة مرور حسابك في أي وقت.

## ملاحظات أمنية مهمة

- غيّري `SETUP_KEY` في `config/config.php` قبل رفع الموقع، ولا تشاركيها.
- فعّلي HTTPS على نطاقك (أغلب الاستضافات توفر شهادة SSL مجانية)، ثم غيّري
  `define('FORCE_HTTPS', false);` إلى `true` في `config/config.php`.
- الموقع محمي ضد: محاولات الدخول المتكررة (يتوقف بعد 5 محاولات خاطئة لمدة
  15 دقيقة)، رفع ملفات غير آمنة، هجمات CSRF، وحقن SQL (كل الاستعلامات مُجهّزة).
- لا تحذفي ملفات `.htaccess` الموجودة في المجلدات - هي التي تمنع الوصول المباشر
  لملفات الإعدادات وقاعدة البيانات وملفات الرفع.

## هيكل المشروع (للمطورين)

```
config/       إعدادات قاعدة البيانات والأمان
includes/     منطق مشترك (اتصال قاعدة البيانات، الجلسات، CSRF، الرفع الآمن)
admin/        لوحة التحكم بالكامل
assets/       CSS و JS للموقع العام ولوحة التحكم
uploads/      الصور المرفوعة (معرض الأعمال، دراسات الحالة)
index.php     الصفحة الرئيسية للموقع (تُبنى ديناميكيًا من قاعدة البيانات)
contact.php   معالج نموذج التواصل
```
